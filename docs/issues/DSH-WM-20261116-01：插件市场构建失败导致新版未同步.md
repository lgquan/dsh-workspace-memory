# DSH-WM-20261116-01：插件市场构建失败导致新版未同步

## 问题信息

- 发现日期：2026-11-16
- 相关版本：`@flowingspring/dsh-workspace-memory@0.3.1`
- 相关外部系统：`awesome-dsh-plugin/awesome-dsh-plugin`、`dsh-plugin-catalog`、`dshmarket`
- 状态：待处理
- 验证情况：已确认本项目 NPM 与 GitHub 发布正常；市场上游夜间构建失败，目录仍停留在旧快照

## 问题描述

`0.3.1` 已发布超过一天，但 DSH 插件市场仍显示 `0.2.16`。NPM Registry、GitHub 标签和 Release 均正常，问题发生在市场目录的自动生成与发布链路，不是本项目发包失败。

## 证据与复现

- NPM Registry 的 `dist-tags.latest` 为 `0.3.1`，版本发布时间为 `2026-11-14T17:01:21.493Z`，即北京时间 2026-11-15 01:01。
- NPM 中存在完整版本序列 `0.2.16`、`0.3.0`、`0.3.1`，`0.3.1` tarball 和 DSH 元数据可正常读取。
- GitHub `v0.3.1` 标签和 Release 已发布，Release 附件为 `flowingspring-dsh-workspace-memory-0.3.1.tgz`。
- `https://awesome-dsh-plugin.com/plugins.json` 中本插件仍为 `version: 0.2.16`。
- NPM 备用目录包 `dsh-plugin-catalog@2026.1114.20961` 同样仍为 `0.2.16`。
- 市场的 `Build site from README` 夜间任务按 `23 2 * * *` 调度，即北京时间每天 10:23 左右执行。
- 发布后的夜间任务 `43667902984` 于 `2026-11-15T02:27:51Z` 启动，在 Build 步骤失败，后续网站部署和 catalog NPM 发布步骤全部跳过。
- 失败日志的最终错误为：

```text
MarketIndexError: $.plugins[1950].name duplicates dsh-dot-mcp
```

- 上游已创建 Issue `awesome-dsh-plugin/awesome-dsh-plugin#15569`，确认夜间构建失败会使 NPM 版本快照冻结。
- 上游已有修复 PR `awesome-dsh-plugin/awesome-dsh-plugin#15579`，当前为开放、可合并状态。

## 影响

- 市场页面仍向用户展示 `0.2.16`，无法体现 `0.3.0` 和 `0.3.1` 的修复与新能力。
- 通过 NPM 显式安装 `@flowingspring/dsh-workspace-memory@0.3.1` 不受影响。
- 该夜间任务失败会影响所有依赖 NPM 版本探测的插件，并非本插件单独被过滤。

## 原因判断

市场夜间任务已经在本插件发布后运行，具备探测到 `0.3.1` 的时间条件。但目录中两个条目解析为同一个 NPM 包名 `dsh-dot-mcp`，最终索引验证将整个构建判定为失败，导致新探测结果没有部署到网站，也没有发布到 `dsh-plugin-catalog`。

本插件的市场源配置还保留了一个独立的低优先级问题：`data/plugins/lgquan__dsh-workspace-memory.yml` 中 GitHub 备用 tarball 固定指向 `v0.2.14`。市场显示的 NPM 版本来自独立探测，因此这不是本次停在 `0.2.16` 的根因，但应在后续提交中更新或移除固定链接。

## 解决方案

1. 等待或推动上游合并 `#15579`，使单个重复包名不再导致整个市场索引构建失败。
2. 上游修复合并后，等待下一次成功的全量夜间探测，或由市场维护者手动运行 `workflow_dispatch` 并启用 `probe_all`。
3. 单独向市场目录提交变更，将本插件备用 tarball 从 `v0.2.14` 更新为当前 Release，或按市场推荐方式取消固定版本链接。
4. 不需要重新发布 NPM，也不需要修改本插件 `package.json` 的版本或 DSH 元数据。

## 处理记录

- 2026-11-16：核对 NPM `latest`、版本发布时间、tarball、DSH 元数据、GitHub 标签与 Release，均正常。
- 2026-11-16：直接读取网站和 NPM 两套市场目录，均复现本插件仍显示 `0.2.16`。
- 2026-11-16：读取市场工作流、失败任务步骤和构建日志，确认失败由无关的 `dsh-dot-mcp` 重名条目触发。
- 2026-11-16：确认上游 Issue `#15569` 和修复 PR `#15579` 已存在，当前无需在本插件仓库重新发包。

## 后续低优先级优化

- 将市场目录中的 GitHub 备用 tarball 从 `v0.2.14` 更新到最新稳定 Release，避免 NPM 不可用时安装到过旧版本。
