# DSH-WM-20261114-04：记忆设置页缺少手工编辑与删除能力

- 发现会话：Codex 会话 `01a1d968-d8ce-7a33-b881-8e10529087ef`
- 相关模块或代码：`src/core.ts`、`src/index.ts`、`src/client/index.tsx`
- 状态：已解决
- 验证情况：已完成核心手工修订、软删除、冲突收敛、Browser API、设置页操作和类型双语标签；类型检查、41 项测试和构建通过

## 问题描述

设置页可以查看结构化记忆和历史版本，但不能直接修正或删除单条错误记忆。用户排查出错误后只能等待模型纠正或手工修改存储文件，后者会绕过串行写入、敏感信息检查、版本历史和摘要重建。

## 影响

- 错误记忆不能在发现后立即由用户修正。
- 直接编辑 JSON 容易破坏数据结构或使稳定摘要继续保留旧内容。
- 单条删除能力虽然存在于 Agent 工具中，但没有提供给设置页用户。

## 解决方案

1. 在记忆引擎增加按 scope 与 ID 更新条目的显式接口，复用现有内容规范化和凭据检查。
2. 更新前把旧标题、描述和内容写入 `revisions`，记录 `manual` 来源，并立即原子写入条目、重建摘要。
3. 设置页为活动记忆提供编辑和删除操作；编辑字段包括标题、内容、标签、类型和重要度。
4. 删除复用现有软删除接口，使条目退出召回和摘要但继续保留在审计数据中。
5. 回收区保持只读；项目级永久删除继续使用已有的回收区清理流程。
6. 记忆类型在列表和编辑下拉框中使用本地化双语标签；中文界面显示 `偏好（preference）`、`决策（decision）`、`架构（architecture）`、`规则（rule）`、`事实（fact）`、`修复（fix）`，同时保留底层英文枚举值以便排查数据。
